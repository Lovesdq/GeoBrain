# 应力约束三维地质软数据流水线中文总结

## 1. 项目目标

本次实现的目标是在 GeoBrain 仓库中构建一套科研级三维地质软数据生成流水线，用于将百万点级规则网格点表 `grid.csv` 转换为可用于 TGRS / Nature 系列论文实验的岩石物理、地震、层位和应力约束软数据。

本流水线不是普通机器学习预处理，而是以地质、岩石物理、地应力代理和地震正演近似为主线，形成如下链路：

`硬数据点表 -> 规则三维网格 -> QC -> 应力代理特征 -> 岩石物理 -> 弹性阻抗属性 -> AVO/合成地震 -> 层位概率/SDF -> 消融实验和论文图件`

## 2. 当前数据字段解释

当前 `grid.csv` 的字段已在 `config.yaml` 和中文 README 中明确写入：

| 原始列名 | 解释 | 标准名 |
|---|---|---|
| `x` | X 坐标 | `x` |
| `y` | Y 坐标 | `y` |
| `z` | Z/深度坐标 | `z` |
| `PORO` | 孔隙度 | `porosity` |
| `GR` | 自然伽马 | `gamma` |
| `SOG` | 含油饱和度 | `oil_saturation` |
| `SH` | 地应力代理量 | `stress` |
| `PR` | 渗透率 | `permeability` |
| `BI` | 脆性指数 | `brittleness_index` |
| `sh1` | 垂向最大地应力/最大主应力代理 | `SH1` |
| `sh2` | 垂向最小地应力/最小主应力代理 | `SH2` |
| `OilPhase` | 储层分类 | `facies` |

默认单位约定：

- `PORO/SOG/BI` 为百分数，内部计算时转为 fraction。
- `GR` 为 API。
- `PR` 为 mD。
- `SH/sh1/sh2` 为 MPa。
- `z` 作为深度方向，默认正向向下。

## 4. 已实现模块

### 4.1 `data_schema.py`

负责：

- 读取 `config.yaml`。
- 根据别名自动识别列名。
- 将 `OilPhase` 编码为 facies 类别。
- 输出 `metadata.json`。

本轮已更新：

- `PR` 被识别为 `permeability`。
- `SH` 被识别为 `stress`。

### 4.2 `grid_builder.py`

负责：

- 从 `x,y,z` 恢复规则三维张量。
- 自动推断 `nx,ny,nz,dx,dy,dz`。
- 检查缺失网格点、重复点、规则间距和坐标单调性。

真实 `grid.csv` 运行结果：

- 网格形状：`124 x 283 x 30`
- 理论节点数：`1,052,760`
- 实际行数：`1,048,575`
- 缺失节点：`4,185`
- 重复节点：`0`
- 间距：`dx=10 m, dy=10 m, dz=5 m`

### 4.3 `qc.py`

负责：

- 统计每个属性的 min/max/mean/std/percentile。
- 检查 NaN、Inf 和物理范围异常。
- 输出 QC 图件。

真实数据中以下属性均有 `4,185` 个 NaN，对应缺失网格节点：

- `porosity`
- `oil_saturation`
- `brittleness_index`
- `SH1`
- `SH2`
- `permeability`
- `gamma`
- `stress`

### 4.4 `stress_features.py`

从 `SH1/sh1` 和 `SH2/sh2` 生成：

- `differential_stress = SH1 - SH2`
- `stress_ratio = SH1 / SH2`
- `stress_anisotropy_index = (SH1 - SH2) / (SH1 + SH2)`
- `mean_stress_proxy = 0.5 * (SH1 + SH2)`

从 `SH` 生成：

- `stress_MPa`
- `stress_MPa_norm`

本轮新增 `Pp/Sv` 地质力学代理扩展：

- 若输入存在 `pore_pressure/Pp` 和 `vertical_stress/Sv`，优先使用列值。
- 若缺列，使用 `Pp(z)=Pp0+0.00981*(z-datum)` 和 `Sv(z)=Sv0+0.023*(z-datum)` 的深度梯度代理。
- 输出 `pore_pressure_MPa`、`vertical_stress_Sv_MPa`、`effective_pressure_physical_MPa`、`overpressure_ratio`、`effective_pressure_ratio`。
- 对 `Sv <= Pp`、`Pp < 0`、缺列代理估计和不完整列填充写入 warning 与 `geomechanics_metadata.json`。

同时检查：

- `SH1 < SH2`
- `SH2 <= 0`
- 应力单位转换

### 4.5 `rock_physics_stress.py`

实现两类方案：

方案 A：弱物理方案

- 常数 effective pressure 下生成 `Vp/Vs/rho`。
- 使用 `mean_stress_proxy` 和 `stress_anisotropy_index` 对 `Vp/Vs/rho` 做经验修正。

方案 B：强物理方案

- 复用 GeoBrain `SoftSand + Gassmann`。
- 将常数 effective pressure 替换为空间变化的 `effective_pressure_proxy_MPa`。
- 输出 `Vp`、`Vs`、`density`、`Vp/Vs`、`AI`、`SI`、`EI_12`、`EI_24`、`EI_36`。

本轮新增方案 C：`Sv-Pp` physical effective-pressure 扩展

- `mode="sv_minus_pore_pressure"` 时直接使用 `effective_pressure_physical_MPa`。
- 当前真实数据缺少 `Pp/Sv` 列，因此默认由深度梯度代理生成。
- 与 `mean_stress_proxy` 方案并列输出，用于论文中的扩展实验和差异图，不替代原有 Exp-2/Exp-4。

### 4.6 `seismic_softdata.py`

负责：

- 计算 Shuey 反射系数。
- 生成 12/24/36 度叠前合成地震。
- 生成叠后合成地震。
- 输出 AVO intercept、gradient、curvature。
- 支持高斯噪声版本。

复用：

- GeoBrain `compute_reflectivity`
- GeoBrain `RickerWavelet`
- GeoBrain `create_conv_matrix`
- GeoBrain `Shuey.avo_attributes`

### 4.7 `horizon_softdata.py`

负责：

- 根据储层 facies 提取储层顶/底界面。
- 生成 `reservoir_mask`。
- 生成 `horizon_probability`。
- 生成 `signed_distance_field`。

说明：

GeoBrain 有 implicit modeling 模块，但其接口更适合界面点和方向约束建模，不是直接从完整 facies 体生成 SDF。因此本流水线实现了可靠的 facies/gradient fallback。

## 8. 可直接用于论文的方法描述

本文首先将均匀长方体点云形式的硬数据恢复为规则三维网格，并通过几何一致性检查识别缺失网格节点和属性异常。随后基于孔隙度、含油饱和度、岩性类别和应力代理量构建 stress-conditioned 岩石物理模型。无应力 baseline 使用常数 effective pressure，而应力感知方案将 `sh1/sh2` 派生的平均应力代理量映射为空间变化的 effective-pressure proxy，并输入 SoftSand-Gassmann 岩石物理模型。由此获得的 `Vp`、`Vs`、`density` 被进一步转换为 `Vp/Vs`、`AI`、`SI` 和多角度 `EI`。在地震软数据生成阶段，使用 Shuey AVO 近似计算界面反射系数，并与 Ricker 子波卷积生成叠后和多角度叠前合成地震体。最后，从储层 facies 中提取顶/底界面，构建 horizon probability 和 signed distance field，作为结构软约束。

## 9. 后续可扩展方向

建议后续扩展：

- 接入实测孔隙压力和垂向总应力 Sv，替代当前深度梯度代理。

- 加入真实井震标定，校正矿物和流体参数。
- 将不确定性模拟从默认关闭改为论文实验批处理模式。
- 如果后续有 SEG-Y 标准几何信息，可启用稳定的 SEG-Y 输出。
