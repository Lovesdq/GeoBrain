## 3. 最后一版处理流程

1. **字段映射与 facies 编码**：`data_schema.py` 读取 `config.yaml`，将中文/英文/缩写列名映射为标准变量，并输出 `metadata.json`。
2. **规则网格恢复**：`grid_builder.py` 将点表恢复为 `[nx, ny, nz]` 张量，检查缺失点、重复点、坐标单调性和网格规则性。
3. **QC**：`qc.py` 统计硬数据 min/max/mean/std/percentile、NaN/Inf 和物理范围警告，并输出 QC 图。
4. **应力代理特征**：`stress_features.py` 基于 `SH1/SH2/SH` 生成差应力、应力比、应力各向异性、平均应力代理等。
5. **Pp/Sv/Peff 扩展**：列优先；当前缺列时按 `Pp(z)=0.00981*z`、`Sv(z)=0.023*z`，并计算 `Peff=clip(Sv-Pp,2,80)` MPa。
6. **岩石物理软数据**：`rock_physics_stress.py` 复用 GeoBrain SoftSand + Gassmann + DensityModel + v_from_moduli，输出 Vp/Vs/rho/阻抗/EI。
7. **地震软数据**：`seismic_softdata.py` 使用 Shuey AVO、Ricker 子波和卷积，输出反射系数、叠前/叠后地震和 AVO 属性。
8. **层位/结构软约束**：`horizon_softdata.py` 根据 facies/reservoir mask 提取顶底界面、horizon probability 和 SDF。
9. **消融实验**：`ablation.py` 输出 Exp-0 到 Exp-8 指标，比较 no-stress、stress-proxy、Sv-Pp physical Peff 和 horizon 约束。
10. **可视化**：`visualization.py` 输出 600 dpi 图件；最后一版修复了正交切片图中色标/数字与切片相互遮挡问题。

## 4. 变量命名、由来与应用

### 硬数据规则网格

| 变量 | 中文名 | 命名/由来 |
|---|---|---|
| `porosity` | 孔隙度 | 由原始 PORO/孔隙度列映射，单位 percent，岩石物理中转为 fraction。 |
| `oil_saturation` | 含油饱和度 | 由原始 SOG/含油饱和度列映射，单位 percent，控制流体混合。 |
| `brittleness_index` | 脆性指数 | 由原始 BI/脆性指数列映射，参与甜点和压裂风险代理。 |
| `SH1` | 最大/垂向最大地应力代理 | 由 sh1/SH1 映射，单位 MPa。 |
| `SH2` | 最小/垂向最小地应力代理 | 由 sh2/SH2 映射，单位 MPa。 |
| `facies` | 储层类别 | 由 OilPhase 编码，0=泥岩，1=油层，2=差油层，3=干层。 |
| `permeability` | 渗透率 | 由 PR/渗透率列映射，单位 mD，用于相关性和 QC。 |
| `gamma` | 自然伽马 | 由 GR/伽马列映射，单位 API，用于岩性背景解释。 |
| `stress` | 综合地应力代理 | 由 SH/地应力列映射，单位 MPa，用于相关性和解释。 |

## 7. 如何应用这些输出

- **论文实验输入**：`grid_properties` 是硬数据，`stress_features` 是可解释地应力/地质力学代理，`elastic_*`、`seismic_*`、`horizon_softdata` 是软数据。
- **消融对比**：`elastic_no_stress`/`seismic_no_stress` 是 baseline；`elastic_stress`/`seismic_stress` 是 SH1/SH2 stress-proxy 方案；`elastic_physical_pressure`/`seismic_physical_pressure` 是 Sv-Pp Peff 扩展方案。
- **机器学习特征**：可将 `Vp`、`Vs`、`density`、`AI`、`SI`、`EI_*`、`AVO_*`、`horizon_probability`、`signed_distance_field` 与硬数据拼接，作为储层分类、属性预测、补全或不确定性建模的输入。
- **物理解释**：`AI`、`VpVs`、`AVO_gradient` 可与 facies、孔隙度、含油饱和度、脆性指数和应力代理做相关性/可分性分析。
- **结构约束**：`horizon_probability` 和 `signed_distance_field` 可作为网络训练的辅助通道、损失权重或后处理约束。
- **不应过度解释**：当前 `Pp/Sv/Peff` 是代理估计；若没有实测孔隙压力、垂向应力密度积分、孔隙压力校正、裂缝方位和边界条件，论文中应称为 `stress-conditioned` 或 `physical effective-pressure proxy`，不是严格三维地质力学正演。
